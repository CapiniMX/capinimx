I-IV-V: En cualquier tonalidad estos tres acordes (mayores) bastan para acompañar casi cualquier canción.
Pentatónica menor: Aprende esta escala primero — sirve para improvisar en casi cualquier canción de rock y pop.
Blues = Pentatónica menor + b5: Agrega la nota Gb (entre F y G) a la pentatónica menor para el sonido de blues.
Inversiones: Toca las notas del acorde en diferente orden para sonar más fluido.
Círculo de quintas: C → G → D → A → E → B → F# → Db → Ab → Eb → Bb → F → C. Los acordes adyacentes combinan muy bien.
Para niños: Empieza con C, F y G7. Con esos tres acordes puedes tocar decenas de canciones infantiles.
